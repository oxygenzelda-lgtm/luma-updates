# Luma 1.10.1 混合DNS修补与安全验证

旧实现只要DNS包含一项被拒绝地址便拒绝整个来源，实机出现公网IPv4与过渡IPv6混合导致封面全部退回占位。现在只从校验通过的公网地址建立连接，固定InternetAddress到socket；不再次解析或转发到被拒绝地址。全部地址不合法时零连接，源码仍禁止内网、回环、保留网段与危险重定向，保持HTTPS与TLS证书验证。未自动使用其他DNS/代理服务。

两个新测试RED→GREEN覆盖真实socket入口、混合响应和全拒绝；175项完整回归通过，8项可选采集跳过，静态检查无问题，独立审查无新增具体问题。1.10.0网络、规则、解压、缓存及更新保护完全继承。Pub锁未变，沿用同日66个依赖公开公告查询，不是无未知漏洞保证，不含全部原生/引擎依赖。

当前手机未连接，1.10.1覆盖安装与真实封面恢复待实机核对；此前1.10.0覆盖安装看到原书架和继续阅读。完整系统内更新安装、输入法、手势、Windows交互与持续性能待分别验收。生产云端下载和SHA256通过不等于系统安装验收。临时诊断日志删除，原始设备和书库证据仅本地。完整源码及源码许可尚未公开，公开仓库只分发包与清理文档。
