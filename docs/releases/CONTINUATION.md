## 此前已确认的要求

| 范围 | 保留的要求与当前实现方向 |
|---|---|
| 产品 | 名称Luma，简短英文；本地、无广告，支持小说、日本轻小说及漫画。Android与Windows共用视觉风格，保留不同输入方式。 |
| 手机界面 | 参考HyperOS/Miuix与用户提供的酷安底栏：透明玻璃、紧凑布局、圆润边角、等宽按钮、图标文字对齐。底栏和阅读工具栏抬高；选中块与外框协调，避免过大空隙和拖尾叠层。Flutter玻璃效果不能宣称原生系统折射。 |
| 动效 | 从点击封面、整条继续阅读或来源控件展开，返回到来源；发现卡片和设置也遵循来源逻辑。避免直线裁切、矩形边角、标题细横线闪现、过快生硬跳出。工具栏显示隐藏不改变正文尺寸或位置，隐藏后不接收输入。完整实机流畅性仍需验证。 |
| 页面结构 | 导航为发现、书架、设置，默认发现。发现顶部小说/漫画，不放导入加号；书架顶部小说/漫画与右侧导入。搜索和筛选同行，筛选在最右；书架继续阅读缩成一行，整行可点。手机每排两本/三本可选，默认两本。去除重复大标题、数量宣传文案、内置试读与测试入口。 |
| Windows交互 | 使用统一主题的独立窗口框架，保留拖动、最大化/还原、最小化、关闭、边缘缩放。按键、鼠标、右键、滚轮及Ctrl+滚轮操作适配电脑；不直接照搬触摸逻辑。封面悬停不重复弹出书名。 |
| 阅读与排版 | 最近7天读过显示阅读中，超过7天为阅读过。字号12–36、0.5步长及自定义小数，增加可离线使用的字体。此前研究番茄/飞卢官方网页字号、行距和夜间切换，转化为舒适小说、紧凑小说、原文排版，未宣称复刻其原生应用。支持明亮、黑色、跟随外观；段首缩进、段间距及标题层级一致，保留原文和阅读锚点。字体设置集中在主设置，阅读工具栏中多余入口已移除。 |
| 导入与智能整理 | TXT/Markdown/EPUB/DOCX、ZIP/CBZ及图片文件夹；混合批量导入自动辨认真实格式与内容，不强迫用户先选格式。正文抽查、题材分类、去重，不确定内容留待检查。相同正文但不同插图版本保留；重复导入保留简介与进度；坏文件不阻断全部任务。电脑支持递归文件夹整理。当前是本地启发式，不能宣称云端AI评审或文学质量筛选。 |
| 插图与稳定性 | 修复长小说导入后无响应、重复任务卡片、插图瞬间跳走/找不到、图片拉伸、连续漫画过大及缩放问题。小说当前采用分页，漫画支持逐页/连续阅读、方向与缩放；图片保持比例，恢复阅读位置时不闪封面。既往用户反馈还涉及上下操作体验，接续时应核对实际实现，不能把未实现的小说滚动模式写成已完成。 |
| 设置与关于 | 两端分组、按钮和进入/返回动效统一。增加实用的设置搜索、恢复阅读默认值及上次整理结果。关于页面参考Kazumi的版本、更新记录、项目与第三方许可组织方式，删除占空间的宣传标题。不能把Kazumi的GPL许可证直接当成Luma许可证。 |
| 作者与简介 | 每本书展示作者、简介、题材与原文预览，允许编辑。简介采用规范小说详情组织方式；只提取明确标注的前部内容，不改写小说原文。 |
| 书源 | 用户所说“贝罗”已确认是飞卢。研究番茄、飞卢和公开分享规则，支持书源JSON文件/链接导入、兼容提示、基础CSS/JSON路径规则与公开章节检索。番茄项目需另部署服务，飞卢当前可用性未验证；脚本、登录、解密、复杂表达式、分页目录暂不兼容。不得宣称已经内置可用源。 |
| 更新与备份 | GitHub Releases分发两端安装包、版本清单、校验与更新记录，避免每次连接手机安装。每次展示新增、调整、修复和限制。历史包保持原始字节与签名，不制造缺失版本。项目交接同时留本地及云端；不公开个人小说、阅读记录、凭据、设备标识或聊天原文。 |

1. 读取上述文档和当前Git状态，简短汇报“已完成/待验收/当前阻碍”。不要重新设计已确认页面，也不要重复上传历史安装包。
2. 优先保全未提交源码与个人书库。关于设备、工具、安装目录及签名的本地定位信息见HANDOFF.local.md。
3. 做两端实机验收：来源展开/返回、导航圆角、标题闪线、工具栏开关、简介编辑、批量整理、书源失败提示。测试手机触摸与Windows键鼠，分别记录结果。
4. 规划并验证真实云端更新的检查、下载、校验、安装、退出/重开、原书库与进度保留。不能通过卸载或清数据来完成所谓升级测试。
5. 番茄/飞卢规则只做真实可用性与兼容性调查；需要服务或不支持时明确说明，再确定后续实现。
6. 新功能按用户后续要求继续。实际发布新版本时同步版本号、构建号、两端包、清单和更新记录，不覆盖历史原包或改变签名。
