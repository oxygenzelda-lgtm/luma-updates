旧版本用于回溯和比较。Android 通常不能直接覆盖降级；不要卸载来试旧版而丢失书库。Windows 旧版应解压到独立目录。历史包的早期自制验证样本与当时已知问题保留。

本仓库是安装包与项目文档分发仓库；发布格式参照常见开源项目，尚不代表 Luma 源码已公开或选定开源许可证。


## 1.7.1 · 关于与设置页面、发现书源和书籍删除

**新增与调整**

- 关于页检查更新与更新记录同排，突出检查更新
- 更新记录、项目主页、问题反馈直接打开GitHub，使用外链图标
- 字体字号与排版、帮助、诊断和致谢采用完整页面
- 发现显示已导入书源，支持刷新、查找及进入公开作品搜索
- 书籍详情缩紧比例，右上角增加删除入口

**修复**

- 发现不再展示已下载的本地书架内容
- 从书架删除保留原文件、图片和阅读进度，取消不删除

**限制**

- 完整源码尚未公开，源代码入口标明尚未公开
- 番茄项目需另部署服务；飞卢规则可用性未验证
- 完整两端实机验收与真实云端更新安装尚未完成

## 1.7.0 · 统一设置动效、简介与更新入口

**新增与调整**

- 统一两端设置页面展开、淡入及返回动效
- 书籍详情新增作者、简介、题材与原文预览，允许编辑作者和简介
- 书源 JSON 文件/链接导入，基础 CSS/JSON 路径规则及公开章节检索
- GitHub Releases 版本检查、下载校验及安装入口
- 单本导入自动识别真实格式、题材和内容类型

**修复**

- 移除阅读工具栏里的阅读设置入口，集中在主设置调整
- 重复导入保留已有简介和阅读进度
- 弹窗关闭动画完成后再释放输入框，修复关闭时控件闪现路径
- 简介只提取明确标注的前部内容，小说原文不改写

**限制**

- GitHub 云端发布和更新端到端验证仍须以真实上线结果为准
- 番茄相关项目需另部署服务；飞卢规则当前可用性尚未验证
- 含脚本、登录、解密、复杂表达式及分页目录的书源暂不兼容
- 99项自动测试与静态检查通过；实机核对被用户Esc中断，不能宣称完整实机验收

## 1.5.0 · 设置统一与自动智能整理

**新增与调整**

- 混合文件自动识别真实格式、内容类型和题材，自动归入对应书架
- Windows 支持递归整理文件夹，单次最多2000个文件
- 设置搜索、恢复阅读默认值、书架题材搜索与上次整理结果

**修复**

- 正文结合图片去重，不误合并不同插图版本
- 提纲、提示词和不确定内容留待检查，坏文件不阻断整个批次

**限制**

- 本地启发式分类，不调用云端AI，不评价小说文学质量


## 1.4.0 · 离线中文字体与小说排版

**新增与调整**

- 舒适小说、紧凑小说和原文排版，段首缩进、段间距与标题层级

**修复**

- 分页与渲染共用段落样式，调整排版不改写原文与锚点

**限制**

- EPUB仍是基础重排，不保证复杂CSS完整还原
